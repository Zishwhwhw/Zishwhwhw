## Шаг 1. Создать репозиторий профиля

Его пока нет. Название репозитория должно **точно совпадать с логином**: `lyce543`.

1. Открыть <https://github.com/new>
2. **Repository name:** `lyce543` — GitHub сразу подпишет
   *«You found a secret! lyce543/lyce543 is a special repository…»*.
   Если такой подписи нет — имя набрано с опечаткой, README на профиль не попадёт.
3. **Public** (обязательно, иначе профиль его не покажет)
4. Поставить галочку **Add a README file**
5. **Create repository**

## Шаг 2. Залить файлы

### Через браузер, без терминала

1. В репозитории: **Add file → Upload files**
2. Перетащить туда `README.md` и папку `assets` целиком
   (GitHub сохраняет структуру папок при перетаскивании).
3. **Commit changes**

Папку `.github` перетащить не выйдет: в macOS Finder папки, начинающиеся с точки,
скрыты. Два варианта:

- **Показать скрытые файлы:** в Finder нажать `Cmd + Shift + .` — папка `.github` появится,
  дальше перетащить как обычно.
- **Или создать файл прямо на GitHub:** **Add file → Create new file**, в поле имени
  вписать `.github/workflows/snake.yml` (папки создадутся сами), вставить содержимое
  файла из этой папки, **Commit**.

### Через терминал

```bash
cd ~/Desktop/senbonzakura-profile
git init -b main
git add -A
git commit -m "Senbonzakura profile"
git remote add origin git@github.com:lyce543/lyce543.git
git push -u origin main
```

`ИНСТРУКЦИЯ.md` заливать не нужно — это файл для тебя, не для профиля.
Можно просто удалить его перед `git add`.

## Шаг 4. Включить змейку

Змейка генерируется GitHub Action'ом и лежит в ветке `output` того же репозитория.

1. Вкладка **Actions** → если предложит — **I understand my workflows, go ahead and enable them**
2. Слева выбрать **Generate contribution snake** → **Run workflow** → **Run**
3. Через ~40 секунд в репозитории появится ветка `output`, и картинка в README оживёт

**Пока Action не отработал, змейка в README будет битой картинкой — это нормально.**
Дальше она обновляется сама раз в сутки.

## Как поменять шапку

Имя в шапке зашито в SVG. Перегенерировать:

```bash
python3 tools/make-banner.py "ДРУГОЕ ИМЯ" "ДРУГАЯ ПОДПИСЬ" > assets/banner.svg
```

Третьим аргументом можно передать число — это seed, он меняет раскладку лепестков:

```bash
python3 tools/make-banner.py "LYCE543" "PYTHON · AI" 42 > assets/banner.svg
```

Цвета — константы в начале скрипта (`#f472b6`, `#fbcfe8`, `#be185d`).
Скрипт ничего не скачивает, нужен только python3.

Гифки меняются просто заменой файлов в `assets/` с теми же именами.

Половина популярных сервисов для README сейчас мертва. В шаблоне используются только живые,
все проверены:

| Виджет | Хост | Статус |
| :-- | :-- | :-- |
| Шапка и разделитель | `assets/*.svg` | ✅ свои файлы, сломаться нечему |
| Печатающийся текст | `readme-typing-svg.demolab.com` | ✅ |
| Статистика, топ языков | `github-readme-stats.shion.dev` | ✅ зеркало |
| Streak | `streak-stats.demolab.com` | ✅ |

| Счётчик просмотров | `komarev.com/ghpvc` | ✅ |
| Волна в подвале | `capsule-render.vercel.app` | ✅ |
| Змейка | GitHub Action в своём репозитории | ✅ |

**Не подставлять** (проверено, отдают ошибку):

- `github-readme-stats.vercel.app` — **503**, официальный инстанс лежит.
  Именно поэтому в шаблоне зеркало `shion.dev`.
- `github-readme-streak-stats.herokuapp.com` — мёртв с закрытия бесплатного Heroku.
- `github-profile-trophy.vercel.app` — **402 Payment Required**.
- `github-readme-activity-graph.vercel.app` — **402**.
- `github-readme-quotes.vercel.app` — **402**.

Если однажды отвалится и `shion.dev` — лечится своим деплоем
[github-readme-stats](https://github.com/anuraghazra/github-readme-stats) на Vercel
и заменой хоста в трёх ссылках.
